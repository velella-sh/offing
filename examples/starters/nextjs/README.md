# Next.js starter kit files

Copy-paste files for the [Next.js starter kit](../../../docs/starters/nextjs.md). Drop them into a Next.js repository at the same paths, then commit an empty or reviewed `.offing-baseline.json`.

| Path in this directory | Destination in your project |
| --- | --- |
| `.github/workflows/offing.yml` | `.github/workflows/offing.yml` |
| `.offing-baseline.json` | `.offing-baseline.json` |
| `.cursor/mcp.json` | `.cursor/mcp.json` (merge the `offing` entry if you already have one) |
| `.cursor/rules/offing.mdc` | `.cursor/rules/offing.mdc` |

Live example: [velella-sh/offing-starter-nextjs](https://github.com/velella-sh/offing-starter-nextjs).
