# State of EOL

The [State of EOL 2027](/reports/state-of-eol-2027/) report measures lifecycle risk in 1,000 popular, recently active GitHub repositories using exact pinned revisions. It lists the observed sample sizes, missing evidence, and commands for reproducing the figures.

The [benchmark corpus tables](reports/state-of-eol-corpus.md) remain available for comparing detectors on their reviewed fixtures and expected findings.
