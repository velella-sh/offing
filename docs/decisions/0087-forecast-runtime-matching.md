# 0087. Share runtime matching across forecast inputs

Use the npm detector's Node release-line matcher for browser manifest
ranges. A scheduled date applies when the declaration remains on that
release line. A workflow's installed Python version uses the same first
applicable runtime rule in the browser and terminal. Reuse the npm lock
reader for v1 resolved packages and use the known requirements filename to
select the Python parser.

The repository selector retains evidence from all selected supported
files. A parity run uses the terminal at the repository root and at the
directories of selected manifests, preserving findings in standalone
projects outside declared workspaces. Compare keyed rule, date, and path
evidence using each consumer's pinned registry and the same UTC day.
