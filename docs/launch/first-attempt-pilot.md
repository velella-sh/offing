## Outcome

An **unassisted verified edit** has a local diff that addresses an eligible
lifecycle finding and a targeted verification that confirms the change.
Rescan the affected declaration or use a focused check that confirms the
original finding is resolved. Use that same standard on both routes. Participants can use the assigned tool
and its documentation. Record any facilitator help that directs setup,
chooses a finding, suggests an edit or command, or interprets verification.
