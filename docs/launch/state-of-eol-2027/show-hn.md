# Show HN submission notes

Submit the interactive gallery if you worked on it and can discuss the work personally. Write the title, submission text, and comments yourself in accordance with the current [Hacker News guidelines](https://news.ycombinator.com/newsguidelines.html) and [Show HN guidelines](https://news.ycombinator.com/showhn.html).

- Submit the [interactive gallery](https://velella.sh/offing/gallery/state-of-eol-2027/) as the entry point and cite the [dated study](https://velella.sh/offing/reports/state-of-eol-2027/) for the figures.
- To demonstrate the gallery, select one of the 50 projects, review the prefilled repository and exact commit, then approve the browser's public-file fetch. The gallery runs without an account.
- Explain that the study scanned all 1,000 exact commits from public GitHub repositories. It found 383 of the 1,000 scanned repositories with at least one observed runtime past end of life on November 27, 2026 UTC. The browser uses current signed data and reads a bounded set of supported public files.
- Use the evidence when readers ask how a number or file was selected. [Raw inputs and reproduction](https://github.com/velella-sh/offing/tree/main/benchmarks/state-of-eol) · [Forecast file selection and network limits](https://velella.sh/offing/forecast-web/#public-repository-links)
