Use November 27, 2026 UTC as the analysis date. The cohort covers 1,000 popular and recently active public GitHub repositories. One exact pin remained unavailable after retry. Cite the sample and denominator when quoting a result. The browser gallery uses current signed lifecycle data while the study records observations at its analysis date.
